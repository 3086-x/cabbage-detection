# 噪声预算合成：一个结论到底要多大的差异才站得住

两个**独立**的噪声源，回答的是两个不同的问题：

| 噪声源 | 测法 | 量级 | 回答的问题 |
|---|---|---|---|
| 评估端 | 配对 bootstrap（75 图 × 1000 次） | 半宽 ±0.56pp | 给定这两个权重，换一批同分布的图还成立吗 |
| 训练端 | 每配置 3 个种子重训 | 配对 σ = 0.10~1.16pp | 换一个随机种子重训，这个配置还能更好吗 |

```
SE_total = sqrt( SE_eval² + (σ_paired / √n)² )      CI = Δ ± z · SE_total
```

- `Δ` = **3 个种子的配对均值**（同一 seed 下配置 − 基线，再平均）
- `SE_train = σ_paired / √n`：均值的不确定度，不是单次训练的不确定度
- `SE_eval` **不除以 √n**：75 张 test 是固定的一份样本，多训几个种子消不掉「这份测试集偏难/偏易」这个共同偏差
- 基线 mAP50-95 = 0.7910（base_v2）

## 单次点估计错得有多离谱

把 seed 0 的单次 Δ 和三种子均值并排放，能直接看出「一次训练」这个样本量有多不靠谱：

| 配置 | seed 0 单次 Δ | 三种子 Δ 均值 | 偏差 | 配对 σ | 逐 seed Δ |
|---|---|---|---|---|---|
| YOLOv8n | -2.52pp | -2.30pp | -0.22pp | 0.31pp | -2.47 / -1.95 / -2.49 |
| 加 MixUp 0.15 | -1.35pp | -1.06pp | -0.29pp | 0.25pp | -1.33 / -0.84 / -1.01 |
| +CBAM | -2.15pp | -0.77pp | -1.38pp | 1.20pp | -2.15 / -0.09 / -0.06 |
| 残差CBAM@SPPF | -0.93pp | -0.54pp | -0.38pp | 0.45pp | -0.93 / -0.64 / -0.05 |
| CBAM@P3 | -1.68pp | -0.49pp | -1.19pp | 1.12pp | -1.68 / +0.54 / -0.32 |
| +SE | -0.74pp | -0.36pp | -0.37pp | 0.71pp | -0.74 / -0.80 / +0.45 |
| +CA | -0.57pp | -0.19pp | -0.38pp | 0.35pp | -0.57 / +0.13 / -0.13 |
| 无 Mosaic | +1.25pp | +0.59pp | +0.66pp | 0.57pp | +1.25 / +0.23 / +0.30 |
| 无Mosaic+CBAM | +0.46pp | +0.74pp | -0.29pp | 0.25pp | +0.47 / +0.80 / +0.97 |
| 无Mosaic+CA | -0.24pp | +0.75pp | -0.98pp | 0.91pp | -0.23 / +1.57 / +0.90 |

最夸张的是 **+CBAM**：seed 0 单次给出 -2.15pp，三种子均值只有 -0.77pp，差了 1.38pp —— 而它的配对 σ 是 1.20pp，单次结果整个落在自己的噪声里。**任何用单种子排序的消融表，都可能把这种抖动当成结论。**

**同一份数据、两种口径的差别**：如果只看评估端，3 个配置显著；把训练端噪声算进来后，只剩 2 个能过 Bonferroni。
这就是为什么「配对 CI 很窄」不能直接当成「效应显著」—— 它只证明了这两个权重之间有差别，没证明这个配置换一次训练还会有差别。

## 训练端 σ 不是一个常数

| 配置 | n | 组内 σ | 相对基线的倍数 |
|---|---|---|---|
| +CBAM | 3 | 1.16pp | 5.1× |
| CBAM@P3 | 3 | 1.00pp | 4.4× |
| +SE | 3 | 0.89pp | 3.9× |
| 无Mosaic+CA | 3 | 0.80pp | 3.5× |
| 无Mosaic | 3 | 0.68pp | 3.0× |
| 残差CBAM | 3 | 0.58pp | 2.6× |
| 无Mosaic+CBAM | 3 | 0.35pp | 1.6× |
| +CA | 3 | 0.28pp | 1.2× |
| 完整增强 | 3 | 0.23pp | 1.0× |
| 加MixUp | 3 | 0.22pp | 1.0× |
| YOLOv8n | 3 | 0.10pp | 0.4× |

**这一列数字否掉了一个假设**：最早只测了基线两个档位（σ = 0.23 / 0.68pp），然后把它当成所有配置的通用训练噪声。实测下来注意力类配置的 σ 落在 0.28~1.16pp，最高到基线的 5.1 倍 —— 参数更多、收敛更不稳，随机性不是同一个量级。拿基线的 σ 去判定注意力类配置，方向上**偏乐观**，会把「其实只是抖了一下」的差异误判成「显著」。

## 交叉验证：两种提问方式

每一种配置现在都有「配对 bootstrap（seed 0 两个权重）」和「三种子配对（换 3 次训练）」两组数字。前者问「这两个权重谁更好」，后者问「这个方法是不是更好」：

| 配置 | 配对 bootstrap Δ | 三种子配对 Δ | 差异 | 两种口径方向一致？ |
|---|---|---|---|---|
| YOLOv8n | -2.52pp | -2.30pp | -0.22pp | 是 |
| 加 MixUp 0.15 | -1.35pp | -1.06pp | -0.29pp | 是 |
| +CBAM | -2.15pp | -0.77pp | -1.38pp | 是 |
| 残差CBAM@SPPF | -0.93pp | -0.54pp | -0.38pp | 是 |
| CBAM@P3 | -1.68pp | -0.49pp | -1.19pp | 是 |
| +SE | -0.74pp | -0.36pp | -0.37pp | 是 |
| +CA | -0.57pp | -0.19pp | -0.38pp | 是 |
| 无 Mosaic | +1.25pp | +0.59pp | +0.66pp | 是 |
| 无Mosaic+CBAM | +0.46pp | +0.74pp | -0.29pp | 是 |
| 无Mosaic+CA | -0.24pp | +0.75pp | -0.98pp | **否** |

10 个配置里有 **1 个方向翻转过**。这不是哪一个数字错了，而是两个问题本来就可以有不同答案：某个权重确实更好，不代表产出它的那个方法更好。

## 局限

1. n=3 时标准差极不可靠（σ 的 90% CI 约 [0.58s, 4.4s]），所以合成后的 CI 只到量级，**不报 p 值**。
2. 合成假设两个噪声源独立、且近似正态。前者成立（一个来自数据抽样，一个来自训练随机性）。
3. 三种子均值的评估端 SE 仍取 seed 0 那一对的配对半宽作为代表值。严格做法是对 3 个权重各做一次配对 bootstrap 再合并，但评估端 SE 主要由 75 张图决定，三个权重之间差别很小。

## 结论

- **2 个配置的差异能扛住双重噪声 + 多重比较校正**：YOLOv8n、加 MixUp 0.15，效应量 1.1pp~2.3pp。
- 其余 8 个配置（+CBAM、残差CBAM@SPPF、CBAM@P3、+SE、+CA、无 Mosaic、无Mosaic+CBAM、无Mosaic+CA）的差异落在不可区分区，不应作为结论使用。
- 本表只判 mAP50-95。mAP50 的判定见 `seed_variance.md`：33 个 run 里最大的组间差只有 0.06pp，比它自己的种子 σ 还小 —— 它在这批数据上已经彻底饱和。

**过线结论有多稳**：把 3 种子的配对 σ 往上推到多少，它就会翻转成不可区分？

| 配置 | 当前配对 σ | 临界 σ | 余量 |
|---|---|---|---|
| YOLOv8n | 0.31pp | 1.32pp | 4.3× |
| 加 MixUp 0.15 | 0.25pp | 0.38pp | 1.5× |

余量 1.x 倍的意思是：只要该配置的真实 σ 是当前估计的 1.x 倍，这个结论就站不住。所以过线不等于铁板钉钉 —— 它是「在现有证据下最值得说的一句」，而不是「已经证明」。

**这张表怎么用**：看到任何一个组间差异，先找它落在哪一行 —— 能过 Bonferroni 的才写进结论，其余只能说「观测到，但不足以区分」。
